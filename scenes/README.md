# scenes/ — NPC 성격 글 · 시험 대사 (보류 · AI NPC 를 할 때만 · 담당 미정)

코딩 없이 **글(.md)만** 쓰는 폴더예요. AI NPC 서버(`server/`)가 여기 글을 그대로 읽어서 AI 에게 넘겨요.
규격: [docs/roles/contract.md](../docs/roles/contract.md) · 할 일: [docs/roles/server-on-hold.md](../docs/roles/server-on-hold.md)

```
scenes/
├─ README.md          ← 지금 이 파일 (아래 틀을 복사해서 써요)
├─ personas/
│  ├─ ssam.md         ← 박 쌤
│  ├─ minjun.md       ← 민준
│  ├─ parent.md       ← 민준 어머니 (고딩 루트에선 "엄마")
│  └─ friend.md       ← 서연
└─ test-lines.md      ← 시험용 대사 30줄
```

## 성격 글 틀 (복사해서 쓰기)

`## 제목` 6개는 **그대로** 두고, 내용만 채워요. 한 파일 1,500자 안쪽.

```markdown
# (인물 이름)

## 기본
나이 · 역할 · 성격 2~3줄

## 말투
존댓말/반말, 자주 쓰는 말버릇, 대사 예시 2~3개

## 숨은 사정
상대가 모르는 이 사람의 하루 (엔딩 "서로 몰랐던 일" 재료)

## 좋아하는 말 (호감 +)
- 
- 

## 싫어하는 말 (호감 −)
- 
- 

## 장면별 상황
- 쌤 루트 ○번 (시간 · 장소): 이 사람이 어떤 마음으로 와 있는지
- 고딩 루트 ○번 (시간 · 장소): 
```

> 실제 사람 이름 · 실제 학교 사건은 쓰지 않아요. 모두 만든 이야기예요.
