### 13:12 · "zeb 같은 AI 로 대답받는 건 어때?" → "LLM 말고 JSON 으로 대답하는 AI"
- "zeb" 라는 AI 는 검색해도 찾지 못했어요. 비슷한 이름인 **제타(zeta, 스캐터랩)** 는 공식 개발자 API 를 찾지 못했어요.
- 비공식 연결 라이브러리는 로그인 정보 유출 · 계정 정지 · 약관 위반 위험이 있어서 쓰지 않아요.
- **JSON 으로 답하는 건 LLM 의 기능**이에요. Claude · Gemini · ChatGPT API 에 "이 형식으로만 답해" 라고 시키면 돼요.
  ```json
  { "say": "NPC 대사", "trust": 2, "why": "이유 한 줄" }
  ```
- 감정 분석 AI 처럼 점수만 주는 AI 도 있지만, NPC 대사는 못 만들어요.
