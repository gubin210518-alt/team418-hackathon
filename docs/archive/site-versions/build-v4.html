연결 전에 확인할 것

  • 선을 꽂거나 뺄 때는 USB를 먼저 빼요. 켜진 상태에서 5V 선이 GPIO나 3V3 핀에 닿으면 보드가 망가질 수 있어요.
  • RFID-RC522는 3.3V 전용이에요. VCC를 5V 줄에 꽂으면 모듈이 망가질 수 있어요.
  • 버튼과 리미트 스위치는 저항 없이 연결해요. 코드에서 INPUT_PULLUP으로 두면 누를 때 LOW가 돼요. 리미트 스위치는 COM과 NO 단자를 써요.
  • LED 15칸을 다 밝게 켜면 전류가 많이 흘러요. 칸당 최대 약 60mA라서 전부 흰색 최대면 0.9A 가까이 돼요. 코드에서 밝기를 낮게(예: 255 중 50) 두고, 그래도 재부팅되면 5V 2A 어댑터를 5V 줄에 넣고 GND를 같이 묶어요.
  • LED 데이터선은 DIN 쪽 끝에 연결해요. 스트립에 그려진 화살표가 나가는 방향의 반대쪽 끝이 입력이에요. 데이터선 중간에 330Ω 저항을 넣어요.
  • DFPlayer RX 앞에 1kΩ 저항을 넣어요. microSD는 FAT32로 포맷하고 파일 이름을 0001.mp3, 0002.mp3처럼 붙여요.
  • 보드의 D2, D5, D12, D15는 쓰지 않았어요. 부팅 방식에 영향을 주는 핀이에요. RX0·TX0은 업로드에 쓰여서, D34·D35·VP·VN은 입력 전용이고 내부 풀업이 없어서 비워 둬요.
  • 보드에 인쇄된 이름과 코드 번호는 같은 핀이에요. 보드의 D32가 코드의 GPIO32(코드에서는 32)예요.

가공 치수

상판 위치는 상판 왼쪽 앞 모서리에서 잰 값이에요 (가로 → 오른쪽, 세로 → 뒤쪽). 위의 치수를 바꾸면 같이 바뀌어요.

대상위치크기메모

아직 정해지지 않은 것

  • ESP32 보드는 콜드박스 때와 같은 HW-394(30핀, USB-C)로 가정했어요. 집에 있는 보드가 다르면 핀 위치는 달라도 핀 이름(D32 등)으로 연결하면 돼요. 두 번째 ESP32는 예비로 둬요.
  • 조종석 상자 치수를 아직 몰라요. 처음 값(48 × 30 × 10cm)은 제가 가정한 값이에요. 폼보드로 만들지, 있는 상자를 쓸지 정해서 위 칸에 넣어 주세요.
  • 330Ω, 1kΩ 저항은 준비물 탭의 구매 목록에 넣었어요. 1000µF 콘덴서는 LED가 깜빡거릴 때만 사서 넣어요.
  • 네오픽셀 스트립의 길이와 전압을 받아서 확인해야 해요. 모형은 15칸 25cm, 5V로 가정했어요. 12V 제품이면 이 배선으로는 안 돼요.
  • 아케이드 버튼의 색과 장착 구멍 지름은 받아서 재야 해요. 구멍은 버튼 나사 몸통 지름보다 1mm 크게 뚫어요. 모형의 버튼 색은 예시예요.
  • 수화기 모형을 무엇으로 만들지 정해야 해요. 장난감 전화기 수화기나 폼보드로 만든 모형을 받침에 올려 리미트 스위치를 누르게 해요.
  • RFID가 상판을 통과해서 읽히는지 아직 실험하지 않았어요. 안 읽히면 카드 찍는 곳만 상판을 뚫고 얇은 투명 판을 덮어요.
