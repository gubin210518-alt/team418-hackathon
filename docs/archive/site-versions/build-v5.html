패드 2대 · 모니터 1대 · 버튼과 LED는 옵션

역지사지 부스 배치

부스를 어떻게 놓는지, 옵션 버튼과 LED를 ESP32에 어떻게 연결하는지, 무엇을 챙기고 사야 하는지 아래 탭에서 골라 확인해요. 게임은 패드만으로 다 돌아가고, 버튼과 LED는 시간이 남으면 붙여요.

모니터

  • 책상 가운데 뒤에 세워요. 지나가는 사람이 멀리서도 보게 높이를 올려요.
  • 공용 화면: 시간, 지금 사건, 두 사람 상황, 15칸 게이지.

패드 두 대

  • 왼쪽 쌤, 오른쪽 고딩. 두 사람이 나란히 앉아 서로 화면은 잘 안 보이게 살짝 바깥으로 돌려요.
  • 브라우저로 노트북 주소에 접속해요. 설치는 없어요.

노트북

  • 뒤 오른쪽에 두고 게임 서버를 켜요. 모니터는 HDMI로 연결해요.
  • 옵션 ESP32는 이 노트북에 USB로 꽂아요.
행사장 와이파이는 믿지 않아요. 휴대폰 핫스팟이나 작은 공유기 하나에 노트북과 패드 두 대를 같이 붙여요. AI 켬 모드만 인터넷이 필요하고, 끊기면 AI 끔 모드로 바로 넘어가요.

연결 전에 확인할 것

  • 선을 꽂거나 뺄 때는 USB를 먼저 빼요.
  • 버튼은 저항 없이 연결해요. 코드에서 INPUT_PULLUP으로 두면 누를 때 LOW가 돼요.
  • LED 밝기는 코드에서 낮게(255 중 50쯤) 둬요. 15칸을 다 밝게 켜면 USB 전류가 모자랄 수 있어요.
  • LED 데이터선은 DIN 쪽 끝에 연결해요. 스트립의 화살표가 시작되는 쪽이에요.
  • ESP32는 와이파이 대신 USB로 노트북과 이야기해요. 버튼을 누르면 “STAMP”, “ASK”를 보내고, 서버가 “LED 7”처럼 칸 수를 보내요. 행사장 와이파이가 흔들려도 버튼은 안 끊겨요.
  • 서버는 버튼 신호와 패드 터치를 똑같이 처리해요. 배선이 안 되면 USB만 빼면 돼요.
