# AI 도구 정리

## NPC 대사 · 점수 AI

- 방식: **LLM API + 캐릭터 설정(시스템 프롬프트) + JSON 출력**
- 받을 모양 (서버가 검사해서, 틀리거나 5초 넘으면 미리 쓴 대본으로 전환)
  ```json
  { "say": "NPC 대사", "trust": 2, "why": "점수 이유 한 줄" }
  ```
  - `trust` 는 -2 ~ 3 정수만 허용
- 후보: Claude · Gemini · ChatGPT API 중 하나 — **아직 미정**
- 고르는 기준: 한국어 자연스러움, JSON 을 잘 지키는지, 응답 5초 이내, 무료 한도 / 요금, 학생 대상 안전성
- 지킬 것: 키는 서버(`server/`)에만, 입력 80자 제한, 최근 대화 6줄만 전송, 개인정보 보내지 않기, 월 사용 한도 걸기
- 다른 AI 의 API 키를 쓸 때는 **쓰기 전에 팀에 말하기**, 결제는 **선생님과 먼저 상의**

- 무료 요금제, 크레딧 1.52 → 1크레딧 사용 → **남은 0.52**

  | 모델 | 크레딧 | 무료 요금제 |

  | gpt_image_2_5 | 0.25 | ✗ "Basic 이상 필요" |

## Jev (TypeSafe AI) 검토 — 10/22 밤

연님이 말한 "jeb" 는 **Jev** 였어요. 2026-09 에 나온 모델이라 Claude 가 원래 알던 정보가 아니고, 아래는 웹 자료(대부분 제3자 블로그 + 공식 API 문서) 기준이에요.

- **글을 쓰지 않는 AI** 예요. 상황(`state`)과 질문을 주면 **정해진 모양으로만** 답해요.
  - `score`: 2~10단계 점수 · `choice`: 정해 둔 보기 중 하나(최대 255개) · `noul`: 예/아니오 확률
  - 주소 `POST https://api.typesafe.ai/v1/systemone`, 모델 `jev-latest`. OpenAI 방식(`/chat/completions`)과 **호환 안 됨**
- 우리 게임에 맞는 점: 호감도 점수(`trust`)를 `score` 로 받으면 **점수가 범위 밖으로 나갈 수 없어요.** 장난 입력에도 안정적.
- 안 맞는 점: **NPC 대사(`say`)를 못 만들어요.** → 대사는 미리 써 둔 후보 중 `choice` 로 고르게 하거나, 다른 LLM 을 같이 써야 해요.
- 확인 안 된 것 (직접 확인 필요):
  - **한국어 정확도** — 자료엔 "영어가 가장 정확"이라고만 있어요
  - **가입 가능 여부** — 9/21 "대기 없이 누구나 가입" 이라는 글과 9/22 "신규 가입 일시 중지" 라는 글이 엇갈려요
  - 무료 크레딧($5 라는 글도, 없다는 글도 있음) · 결제 수단 필요 여부 · **나이 제한**(우리는 고등학생)
- 요금: 입력 100만 토큰당 $0.042, 출력 무료 (자료 기준). 그래도 **결제는 선생님과 먼저 상의.**
