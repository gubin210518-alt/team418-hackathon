# 미연시 설계 (사이트 맛보기 버전)

코드 위치: `site/index.html` 안 `/* ===== 미연시 v2` 부분 (`NPC`, `ROUTES` 데이터)
대본을 고친 뒤에는 `node tools/scripts/check_endings.js` 로 못 보는 엔딩이 생기지 않았는지 확인해요.

## 미연시 장르에서 가져온 것

| 미연시 특징 | 우리 게임 |
|---|---|
| 캐릭터별 호감도 | 인물마다 ♥ 점수가 따로 쌓임 (화면 오른쪽 위) + 맨 위 15칸 신뢰 게이지도 같이 움직임 |
| 선택지 분기 · 플래그 | 앞 선택이 뒤 장면 대사와 선택지를 바꿈 (★ 앞 선택 덕분에 생긴 선택지) |
| 멀티 엔딩 | 루트당 7개 + 숨겨진 엔딩 1개 = **15종** |
| 엔딩 도감 | 본 엔딩이 모임. 이 브라우저에만 저장 |
| 연출 | 챕터 카드, 배경 전환, 캐릭터 등장, 하트 터짐, +3 번쩍, 감점 시 화면 흔들림 · 빨간 테두리, 메신저 말풍선, 엔딩 도장 · 색종이 · 비 |
