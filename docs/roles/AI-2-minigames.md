> 맡는 사람: **최호진** · 이 문서는 호진 님의 AI 가 읽고 따라 하는 할 일 목록이에요.
> 먼저 읽을 것: [README.md](../../README.md) → [roles/README.md](README.md) → [contract.md](contract.md) (**특히 5번 미니게임 규격**) → [daily-schedule.md](../daily-schedule.md)

## 한 줄 목표

[일과표](../daily-schedule.md)에 나온 **미니게임 7개**를, 연님의 미연시가 불러 쓸 수 있는 **규격(`MG.○○.start`)** 에 맞춰 만든다. 완성도보다 **규격을 지키고 끝까지 돌아가는 것**이 먼저예요.

## 정해 둔 방식 (바꾸려면 연님과 상의)

- **바닐라 JS(HTML + JS + CSS) 만** 써요. 외부 라이브러리 · npm 없이. (설치 문제 · 보안 걱정 감소)
- 게임 하나 = 파일 하나: `site/minigames/<id>.js` (모양은 [contract.md 5번](contract.md#5-미니게임-규격-ai-2-호진-이-만들고-ai-1-이-불러요))
- **연님의 `index.html` 은 고치지 않아요.** 시험은 `site/minigames/test.html` (직접 만들기) 에서 해요.
- 그림이 필요하면 하선 님 에셋을 쓰되, **없어도 CSS/도형으로 돌아가게** 만들어요. 에셋은 나중에 갈아 끼워요.
- 소리는 `window.SFX` 가 있을 때만 `SFX.play('이름')` 으로. 쓸 수 있는 이름은 `site/sfx.html` 에서 들어 볼 수 있어요. 새 소리가 필요하면 연님에게.

## 할 일 (위에서부터)

### 0단계 · 틀 만들기

- [ ] `site/minigames/test.html` — 버튼으로 게임을 골라 `MG.○○.start()` 를 불러 보고, `done` 결과를 화면에 찍어 주는 시험 페이지 (여기엔 `index.html` 이 없어도 돼요)
- [ ] `site/minigames/common.css` (선택) — 공통 모양

### 1단계 · 1교시 묶음 (가장 먼저 — 서로 이어져요)

- [ ] **① `memory.js` 단기기억**: 짧은 문장(예: 발표 대사 한 줄)을 2~3초 보여 줬다가 가리고, 입력칸에 쳐서 제출 → **일치율 `ratio`(0~1)** 계산
  - 문장 3개 정도 · 글자 단위 일치율(예: 편집 거리) · 한글 입력 조합 중(`compositionend`)에도 안 깨지게
  - 결과: `done({score, ratio, pass})`
- [ ] **② `rhythm.js` 리듬게임**: 발표 수행평가. `opts.memoryRatio` 가 높을수록 쉬워지고(타일이 느리거나 판정이 넓음), 낮으면 어려워져요
  - 키보드(D F J K 또는 방향키)와 **터치** 둘 다. 판정 Perfect / Good / Miss
  - 음악(BGM) 은 하선 님이 110 BPM 으로 만들 예정 → `opts.bpm`(기본 110) 에 맞춰 타일을 내려요. 음악 파일이 없으면 메트로놈 소리/무음으로도 돌아가게
  - 결과: `done({score, ratio, pass, extra:{perfect, good, miss}})`

### 2단계 · 나머지 5개 (규격만 맞으면 대충이어도 돼요)

- [ ] **③ `classify.js` 정보 분류** (2교시 데이터과학): 카드를 알맞은 칸에 끌어놓기/터치 (예: 개인정보 ↔ 공개 가능, 또는 숫자/문자/날짜 같은 자료형)
- [ ] **④ `math.js` 수학문제** (3교시 미적분): 간단한 문제 3개 + **연습장**(손글씨 `canvas` 또는 낙서판). 객관식도 OK
- [ ] **⑤ `sleep.js` 졸음참기** (4교시 · 7교시): 눈꺼풀이 내려오는 걸 연타/길게 눌러서 버티기. `opts.period` 가 7이면 조금 더 어렵게. 실패하면 `pass:false`
- [ ] **⑥ `inquiry.js` 기하 탐구** (6교시 "대충 만들어줘"): 도형 맞추기/점 잇기 정도로 가볍게
- [ ] **⑦ `speedeat.js` 빨리먹기** (저녁): 메뉴 고르기(카드 3장) → 음식 아이콘을 빠르게 눌러 다 먹기. 시간 안에 끝나면 `pass:true`

### 3단계 · 다듬기와 시험 (10/24 ~ 25)

- [ ] 모든 게임: **제한 시간** · **건너뛰기 버튼** · 휴대폰(가로 375px)에서 되는지
- [ ] "움직임 줄이기"(`opts.reduced`) 일 때 번쩍임/흔들림 끄기
- [ ] `start()` 를 두 번 불러도, `stop()` 을 불러도 **타이머가 남지 않는지** (끝나면 이벤트 · 타이머 정리)
- [ ] 연님에게 "○○ 올렸어" 한 줄 (게임 하나 끝날 때마다)
