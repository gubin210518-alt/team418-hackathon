# Part 1 · 서버 (옛 AI 1)

> (옛 제안: 최호진. **지금은 담당 미정**)
> 먼저 읽을 것: [README.md](../../README.md) → [roles/README.md](README.md) → [contract.md](contract.md) → [server/README.md](../../server/README.md)

## 한 줄 목표

플레이어가 입력한 말을 AI 에게 보내고, **NPC 대답 + 호감도 점수**를 `{say, trust, why}` 로 화면에 돌려주는 작은 서버.
진짜 AI 가 안 되면 **절대 멈추지 않고** `{ "error": "fallback" }` 을 돌려줘서 화면이 데모로 넘어가게 해요.

## 정해 둔 방식 (바꾸려면 총괄과 상의)

- **Node.js 만 써요. 외부 패키지(npm install) 없이** 만들어요. (설치 문제 · 보안 걱정이 줄어요)
  - 서버: `node:http` · 파일: `node:fs` · AI 호출: 내장 `fetch`
  - 키 읽기: `node --env-file=.env server/index.js` (Node 20.6 이상. 버전은 `node -v` 로 확인)
- 서버가 `site/` 폴더도 같이 보여 줘요 → 화면과 서버가 같은 주소라서 CORS 설정이 필요 없어요.
- 대회 부스에서는 **노트북에서 켜요** (`http://localhost:8787`). 인터넷에 서버를 올리지 않아요.
  지금 Netlify 사이트(team418.netlify.app)는 서버 없이 **데모 모드**로 계속 돌아가요.
- AI 회사는 아직 미정이에요. 그래서 **갈아 끼울 수 있게** 만들어요.
  - `AI_PROVIDER=mock` → 가짜 AI (0원, 키 없음). **처음엔 이것만** 만들어요.
  - 나중에 선생님과 정해지면 그 회사 것 하나만 추가해요.

## 지금 코드에서 고칠 곳

`site/index.html` 한 파일이에요. 미연시 코드는 `/* ===== 미연시 v2` 부분이에요.

| 무엇 | 위치(찾을 글자) | 지금 하는 일 |
|---|---|---|
| 직접 입력 처리 | `free.addEventListener('submit'` | 좋은 단어 · 나쁜 단어(`POS` · `NEG`)로 점수를 정함 ← **여기를 서버 연결로** |
| 점수 반영 | `function answer(c,said)` | `c.d`(인물별 점수)와 `c.why` 로 하트 · 흔들림 · 게이지를 처리 |
| 장면 데이터 | `var ROUTES=` | 장면 · 대사 · 선택지 · 엔딩 |
| 입력칸 숨김 | `free.hidden=` | 단톡 · 교감 장면에선 입력칸을 숨김 |
