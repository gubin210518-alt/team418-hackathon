
## GitHub 에 올리는 법 (3단계)

1. GitHub Desktop 에서 **Fetch origin → Pull** (남이 바꾼 것 받기)
2. 글을 고친 뒤 왼쪽 아래 **Summary** 에 한국어 한 줄 (예: `민준 성격 글 추가`) → **Commit to main**
3. 위의 **Push origin** 누르기
