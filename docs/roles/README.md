  하선 님 일은 코딩이 아니지만 **필수 제출물(발표 PDF)**이 들어 있어서 가장 중요해요.
- 사람을 바꾸고 싶으면 이 표만 바꾸면 돼요. 문서는 사람이 아니라 **역할** 기준으로 써 놨어요.

## 세 역할이 만나는 곳

세 사람이 동시에 일해도 안 부딪히도록 **약속(규격)**을 먼저 정해 뒀어요 → [contract.md](contract.md)

```
[AI 3] scenes/personas/*.md  ──(NPC 성격 글)──▶  [AI 1] server/  ◀──POST /api/npc──  [AI 2] site/
                                                     │                                  ▲
                                                     └──── { say, trust, why } ─────────┘
```

- AI 1 은 키 없이도 돌아가는 **가짜 AI(mock)** 를 먼저 만들어요. 그래서 AI 2 는 키가 없어도 화면 작업을 시작할 수 있어요.
- AI 3 이 쓴 성격 글은 서버가 **그대로 읽어서** AI 에게 넘겨요. 하선 님은 코드를 몰라도 NPC 성격을 바꿀 수 있어요.

## AI 에게 처음 시키는 법 (세 명 공통)

1. GitHub Desktop 에서 `Fetch origin` → `Pull` (최신으로 받기)
2. 내 AI 에게 저장소 폴더를 열어 주고 아래처럼 말하기

   ```
   README.md, docs/roles/README.md, docs/roles/contract.md, docs/roles/AI-○-….md 를 읽어 줘.
   너는 TEAM 418 의 AI ○ 야. 그 문서의 "할 일" 을 위에서부터 하나씩 하자.
   내가 코딩 초보니까 무엇을 왜 하는지 짧게 설명해 주고, 내 담당 폴더 밖은 고치지 마.
   ```

3. 하나 끝날 때마다 `Commit`(한국어 한 줄) → `Push`
4. 다른 사람 폴더를 고쳐야 하면 **단톡에 먼저** 말하기

## 모두 지킬 것 (보안 · 돈)

- **API 키는 `.env` 에만.** 코드 · 문서 · 단톡 · 이슈 · 커밋 메시지에 붙여 넣지 않기
- 키를 화면(`site/`) 코드에 넣지 않기 — 브라우저 코드는 누구나 열어 볼 수 있어요
- **결제 · 요금은 박민하 선생님과 먼저 상의.** 유료 결제를 누르기 전에 반드시 팀 단톡에 알리기
- 다른 사람의 AI API 키를 쓸 때는 **쓰겠다고 먼저 말하고** 쓰기
- 플레이어가 입력한 말에 이름 · 학번 · 연락처를 넣지 말라고 화면에 안내하기
