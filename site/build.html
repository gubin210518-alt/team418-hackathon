대화 화면

맨 위 줄

  • 시간과 장소로 지금이 하루 중 언제인지 보여 줘요.
  • 신뢰 15칸이 늘 보여요. 바뀔 때 반짝여요.

가운데

  • 배경 4종: 교무실, 복도, 교실, 밤.
  • NPC 표정 3종: 보통, 웃음, 서운함. 신뢰 변화에 따라 바꿔요.

대사창

  • 선택지 3개는 항상 있어요. AI가 꺼져도 이걸로 진행해요.
  • 직접 입력과 누르고 말하기는 AI가 켜졌을 때만 보여요.

패드 가로 화면을 기준으로 그렸어요. 휴대폰 세로 화면에서는 캐릭터를 작게 하고 대사창을 아래 절반에 둬요.

장면 대본 형식 (JSON)

장면 하나가 이 모양이에요. 시나리오 담당은 이 파일만 고치면 게임에 바로 들어가요. AI가 꺼지면 이 대사와 선택지로 진행해요.

{
  "route": "ssam",
  "id": "s1",
  "when": "08:20",
  "where": "교무실 · 전화",
  "npc": "parent",
  "bg": "office",
  "line": "선생님, 저희 애가 수행평가 기준을 몰랐다고 하던데요.",
  "choices": [
    { "say": "공지는 다 했습니다. 아이가 확인을 안 한 거죠.", "trust": -2,
      "why": "사실이어도 탓하는 말로 들렸어요." },
    { "say": "걱정되셨겠어요. 공지를 다시 보내 드릴게요.", "trust": 2,
      "why": "걱정을 먼저 받아 주고 할 일을 말했어요." },
    { "say": "지금 수업 들어가야 해서요.", "trust": -1,
      "why": "언제 이야기할지 정하지 않았어요." }
  ],
  "minigame": "call"
}

AI에 보낼 지시문 (초안)

중괄호 부분은 서버가 채워요. AI는 정해진 JSON만 돌려주고, 서버가 형식과 금지어를 확인한 뒤 화면에 띄워요.

너는 고등학교 하루 체험 게임의 NPC "{npc_name}"이다.
성격: {npc_persona}
지금 장면: {when} {where}. 상황: {situation}
지금 신뢰: {trust}/15 (낮을수록 날카롭고, 높을수록 먼저 사정을 말한다)
최근 대화:
{history}

플레이어({role})가 방금 한 말: "{player_text}"

규칙
- 실제 사람 이름, 학교 이름, 개인정보를 만들지 않는다.
- 욕설, 비하, 폭력적인 표현을 쓰지 않는다.
- 대사는 한국어 구어체 한두 문장, 60자 이내.
- 플레이어 말이 상대 입장을 헤아렸으면 trust를 올리고, 탓하거나 무시하면 내린다.

아래 JSON 하나만 출력한다.
{"say": "NPC 대사", "trust": -2부터 3 사이 정수, "why": "판단 이유 한 문장"}
  • 5초 안에 답이 없거나 JSON이 깨지면 대본의 선택지로 바로 넘어가요.
  • trust 값이 범위를 벗어나면 서버에서 −2~+3으로 잘라요.
  • 최근 대화는 6줄까지만 보내요. 길게 보낼수록 느리고 비싸져요.
